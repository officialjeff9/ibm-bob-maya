Bob's Viewport: Agentic Technical Art in Maya
Bob's Viewport is a technical artist tool that leverages a custom IBM Bob persona to automate 3D modeling and geometry creation workflows within Autodesk Maya.

Overview
This project streamlines the technical art pipeline by using agentic AI to analyze reference images and generate structured data, which is then translated into modeling steps within the Maya environment.

Project Structure
bridge.py: The core script handling communication between the AI agent and the Maya API.

userSetup.py: Initial setup script to ensure the tool integrates correctly with your Maya environment on startup.

Installation
Clone this repository to your local machine.

Ensure you have Autodesk Maya installed.

Place the scripts in your Maya scripts directory or your preferred project folder.

Run the tools directly within the Maya script editor to initialize the connection.
